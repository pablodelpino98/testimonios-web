# Práctica 1 con React: Web con testimonios #

Este es un ejercicio práctico de un posible apartado de testimonios de usuarios sobre sus experiencias con **React**.

## 🚀 Características

- Buena estructura de los archivos y código.
- Reutilización de componentes.
- Interfaz sencilla y limpia.

## 🛠️ Tecnologías utilizadas

- **React**
- **CSS**
- **JavaScript**

## 📂 Instalación y uso

1. Clona este repositorio en tu máquina local:
   ```sh
   git clone https://github.com/pablodelpino98/testimonios-web.git
   ```
2. Accede al directorio del proyecto:
   ```sh
   cd testimonios.web
   ```
3. Instala las dependencias necesarias:
   ```sh
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```sh
   npm start
   ```
5. Abre tu navegador y accede a `http://localhost:3000` para ver la aplicación en funcionamiento.
